# Taphaptic Privacy Policy

Effective date: July 26, 2026

Taphaptic delivers Apple Watch notifications for lifecycle events generated by
Claude Code and Codex on a Mac controlled by the user.

## Data Taphaptic processes

The hosted relay processes:

- a random installation identifier and scoped authentication tokens;
- the Apple Push Notification service device token for the Taphaptic watch app;
- the selected event source (`claude-code` or `codex`), event kind, time,
  deduplication identifier, and short generic notification title/body;
- limited server security data such as request time and network address.

The built-in adapters do not send prompts, transcripts, repository files, tool
arguments, source code, or generated answers.

## Purpose and sharing

This information is used only to pair the user's Mac and watch, prevent
duplicate alerts, deliver requested notifications through Apple Push
Notification service, prevent abuse, and operate the service. Taphaptic does
not sell data, use it for advertising, track users across apps or websites, or
share it with data brokers.

Apple processes APNs delivery under Apple's own terms and privacy policy.

## Retention and security

The relay keeps only a bounded recent event history for synchronization. Device
registrations and scoped tokens remain until the installation is deleted,
becomes inactive under the service retention policy, or APNs reports the token
as invalid. Pairing codes expire after approximately ten minutes.

Transport to the hosted relay uses HTTPS. Sensitive credentials are stored in
the watch Keychain or protected local files on the user's Mac. Server secrets
are not included in the app.

## Choices and deletion

Users can disable notifications in Apple Watch settings, reset pairing in the
watch app, remove only the Taphaptic entries from Claude Code/Codex, or run:

```sh
./scripts/uninstall.sh --yes
```

The uninstall flow requests deletion of the installation, device
registrations, events, and scoped tokens before removing local files. If the
relay is unavailable, open a private support request through the repository's
security-advisory contact and include the non-secret installation ID. Never
send bearer tokens in a support request.

## Contact and changes

Privacy and deletion requests: use the private security-reporting workflow at
<https://github.com/dzzzgnr/taphaptic/security/advisories/new>.

Material changes will be published in this document with a new effective date.
